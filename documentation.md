## 🧪 Using these references

Read the surrounding explanation before copying code. Separate complete programs from fragments and version-specific examples. Verification recorded by a guide applies to its stated environment; check current tool documentation when versions differ.

The `ai-cli/` files are reusable instruction/configuration examples. Preserve their functional syntax and review personal settings before copying them. They are not a general installation script.
